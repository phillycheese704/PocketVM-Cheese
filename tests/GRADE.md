# Grade School verification

Grade School is an original classroom comedy inspired by the linked Yiv premise. The final interaction requires a real freehand drawing: choose red or green ink, draw on the paper and hand it back. Content consists of eighty absurd prompts, generated snack sums and simple suspicious doodles. It uses its own characters, Canvas artwork, UI, sound and code.

- `grade-regression.cjs`: 15 gameplay checks. Exercises 2,320 generated Snack Maths/Art prompts, thirty complete career days, deterministic daily papers, once-only settlement, timers and opt-out, challenge records, purchases, reloads and bounded red/green strokes cleared after hand-in.
- `grade-package.cjs`: 8 checks using actual production Store functions and a disposable virtual disk. Installs and embeds both scripts, carries an unfinished drawing into the sandbox, accepts only source-checked bounded saves, rejects four truncated downloads, rolls back interrupted writes, repairs while preserving progress, launches offline and keeps progress after uninstall.
- `grade-render.cjs`: 10 checks using actual production scripts, event handlers and native Canvas. Boots the welcome menu, draws the classroom, starts a career paper, draws pointer strokes in real Canvas pixels, saves/undoes strokes, switches colour and hands back a paper. Also tests right-click/secondary-touch rejection, empty coalesced event fallback, undo/redo buttons and keyboard shortcuts, unmodified browser shortcuts, move mode, interrupted strokes, device control relocation, hidden-tab rendering, exact offline URLs and package byte sizes.
- `grade-touch-layout.html`: loads the real game at ten laptop/iPad/phone/split-view sizes. Checks touch targets, horizontal bounds, vertical bounds when not scrolling, paper/control separation and visible errors.

Live verification on build `school-v3` passed all fourteen layout checks: 1024×768, 768×1024, 1366×1024, 507×768, 390×844, 320×568 and 740×390, each with normal and extra-large ink controls. Results are in `grade-ink-layout-results.json`. Red F and green tick strokes were drawn using real browser pointer drags, handed back and rewarded correctly. Reloading before hand-in preserved the red drawing and restored an enabled hand-back button after Continue. `grade-school-ink-1791621675860.jpg` shows the live handwritten grade.

The native render test supplies a small DOM adapter; live browser checks provide the full layout verification. Physical iPad/Apple Pencil hardware and audio playback have not been tested. Pointer support uses the standard browser APIs; a physical device check remains useful.

Build `school-v4` adds a phone control dock, unclipped scrolling papers, explicit move/draw mode, redo, smoothed pressure-weighted ink, fullscreen where available, safe stroke interruption and preserved browser shortcuts. Automated checks pass: 15 gameplay + 8 package + 10 production-render/input checks. Live laptop/mobile verification follows publication.
