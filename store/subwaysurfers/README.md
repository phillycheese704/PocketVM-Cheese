# Subway Surfers · PocketVM

Original fan-inspired implementation and original canvas/SVG artwork. References: the official Subway Surfers homepage and SYBO support's hoverboard descriptions. No original game code, logos, character art or audio copied.

Three lanes, gradual speed increase, seeded random obstacle rows, gaps, overhead signs, barriers, stationary and oncoming trains, ramps and train roofs. Normal jumps clear barriers; upgraded sneaker jumps reach train roofs. Swipe-down accelerates an airborne landing. First light collision brings the guard close; a second within seven seconds ends the run. Train impacts and falls end it immediately. Hoverboards last thirty seconds and absorb one crash; a single key continuation clears nearby hazards. Collected currency and progress bank when the run ends, without duplication after a continuation.

Four original worlds, world-tour changes every 1400m, four cosmetic outfits, three board colours/trails, upgradeable magnet/jetpack/sneakers/double-score power-ups, mission multiplier progression, personal bests and deterministic UTC daily routes. All purchases use earned game coins. Native PocketVM downloadable mods: Permanent Magnet, Moon Shoes, Rush Hour. Separate saves for mod combinations.

Keyboard, swipe and optional big touch buttons; independent pointer capture, safe cancellation, resize handling and pause on focus loss/rotation. Offline Canvas2D perspective rendering, procedural audio, matching icons and source-checked career saves.
