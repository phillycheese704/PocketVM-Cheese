# Knockout
An original PocketVM implementation inspired by the hidden-aim penguin survival format of Roblox Knockout!. Single-player with 7–15 AI rivals, not Roblox multiplayer.

Pick a direction on the ice, set power, and lock in. Rivals' planned aim and power remain hidden. Everyone launches simultaneously; friction and equal-mass collisions resolve at 120 Hz. Each later round shrinks the floe toward the orange warning boundary. Crossing the edge eliminates immediately and triggers a splash; recent collision attribution awards a knockout once.

Three arena outlines, three AI difficulties, Random options, practice, eight earned colour skins, four free hats, saved Ice and career stats. Touch, mouse, and keyboard; pause on backgrounding; safe-area-aware responsive UI. Installed games embed all scripts for offline use. No external runtime assets or libraries.
