# PocketVM game mods

Open Pocket Browser and enter `pocket:mods`. Choose a game filter, download its `.pvmod`, then use Files → Downloads to move it into the matching installed game folder. Relaunch the game to activate it.

| Game | New mod | Effect |
| --- | --- | --- |
| Flappy Bird | Featherweight Flight | Lighter gravity, gentler flaps, slower pipes and wider gaps in Classic and Practice. |
| Penguin Pull | Moon Gravity | Loose penguins fall at 40% gravity and retain more throw momentum. Water rescues still score exactly once. |
| Apex Rush | Nitro Overdrive | Player nitro never runs dry. AI, collisions, off-road limits and crash damage still apply. |
| Ball vs Ball | Pinball Frenzy | Both teams move 30% faster, bounce at wilder angles and recharge abilities 40% faster. Supports all four match modes. |

Each mod uses its own save. On first launch it copies the normal game's current progress; subsequent modded records, coins and unlocks remain separate. Removing the mod restores the original game's save. Modded progress is retained if the mod is installed again.

Downloaded packages stay inactive until moved into the correct game folder. The four new packages are validated data; package contents never execute scripts or change the base game files. Remove them through `pocket:mods` or delete the `.pvmod` in Files, then relaunch. Renaming a valid `.pvmod` does not prevent activation or removal.
