# Match Survival

Original implementation and art inspired by doublespeak games' Gridland: adjacent match-three swaps, resource collection and automatic construction by day; real-time equipment and monster summoning at night. Reference: https://gridland.doublespeakgames.com/ and the developer's public mechanics definitions. No upstream code or assets included.

Seven columns, eight rows; invalid swaps cost nothing. Daytime allows unlimited thinking time and lasts twelve successful swaps. Cascades consume one turn. Wood becomes shields and stone swords. Grain, clay and cloth summon different creatures; mana both charges magic and summons liches. Forge and sawmill upgrades improve equipment; six building chains unlock resources. Every fifth night has a boss that must die before dawn. Complete twenty-five nights and continue endlessly.

Touch tap pairs or swipe; keyboard Tab/arrow navigation and Enter/Space selection. Large item buttons, scrolling mobile workshop, pause on blur/rotation. Original animated canvas landscape and SVG tiles. Procedural sound without external audio dependencies. Saved expeditions include grid, settlement, equipment and creatures. Three native PocketVM mods use isolated saves.
