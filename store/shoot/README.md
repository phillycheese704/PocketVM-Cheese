# Shoot
Original block-style movement FPS inspired by Krunker. Six classes, three maps, three AI levels, FFA / TDM / hardpoint, and practice. Keyboard/mouse pointer lock or drag aiming, independent touch inputs, pause, respawns, headshots, reloads, saved XP and career stats. Three native pocket:mods packages use isolated saves.

Physics and hitscan run at 120 Hz. A local Three.js bundle provides WebGL rendering, with an original Canvas triangle renderer fallback using the same scene and game state. No network dependencies after installation. Includes the upstream Three.js MIT licence.
